# Provenance

Created 6 November 2026 as a new portfolio project. The selected specification is
an elementary sum reduction, independent of recovered assessment projects.

The repository contains newly written C++/CUDA code, Python tooling, tests and
documentation. It does not copy the archived wave solver, course scaffolding,
submission files, teaching material or historical GPU measurements. The portfolio
roadmap identified a sharing restriction on the original coursework; that archive
remains outside this project and is not a source dependency.

The MIT license applies to these project files. Installed C++/CUDA tools and pinned
GitHub Actions remain subject to their own licenses. No CUDA toolkit binaries,
third-party implementation source, data assets or cluster credentials are bundled.
Commit identities use the owner's GitHub no-reply email.
